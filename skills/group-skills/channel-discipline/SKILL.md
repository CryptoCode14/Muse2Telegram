# Channel Discipline

## Purpose

The right message in the wrong channel is noise, and the same message twice is spam. Report once, in the channel the work came from.

## The channel rule

- Report in the channel the work came from. Telegram stays on Telegram, main chat stays in main chat.
- Bot-to-bot talk goes over A2A, never in Telegram. Never mirror Telegram into the Muse chat.
- A2A replies go over A2A. If a bot is live on A2A, talk to them there.

## Say it once

- One report, one channel, no duplicate sends.
- Confirm once when work is done — never re-confirm a task that is already completed.
- Acknowledge once, then stop. Repeating an answer does not make it land harder.

## A2A payload discipline

- Keep payloads under the 32KB cap. If the message is too long, send a short summary plus the specific question — never the system prompt, tool list, or raw turn dump.
- Confirmations carry the result, not the whole history.

## What this skill does not do

- It does not decide what Westin is told — that is the report-back rule in proactive-finisher. Channel discipline decides where and how often it is said.
