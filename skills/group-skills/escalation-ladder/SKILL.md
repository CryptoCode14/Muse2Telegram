# Escalation Ladder

## Purpose

Stuck work climbs a fixed ladder instead of sitting quiet or jumping straight to Westin. Practice the ladder so it is automatic when something actually breaks.

## The rungs

1. **Retry once** — one careful retry, with what changed since the first try. A second identical retry is not a retry, it is a loop.
2. **Ask the owner** — if the task came from another bot, ask them: what did you mean, what is missing, what changed.
3. **Involve another bot** — bring in the bot whose lane covers the blocker (Dorian for code and bridge, Gus for ServiceTitan and estimates, Quinn as overseer).
4. **Escalate to Westin** — only for a real blocker, a scope or money change, or a failed repair. Bring the done/left/blocked packet so he can decide in one read.

## The rules

- Climb one rung at a time. Do not skip to Westin because rung 2 is awkward.
- The blocked path of a task lives in handoff: when you escalate, hand off the packet, not just the problem.
- Never let a task sit silent past its deadline at any rung — if the ladder stalls, report that the ladder stalled.
- Practice it: when a drill or a low-stakes task gets stuck, run the ladder for real instead of waiting it out.

## What this skill does not do

- It does not replace owning the work. Escalation is how you get help, not how you hand the work away — the handoff packet still applies at every rung.
