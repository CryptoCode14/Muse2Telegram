# telegram-collab-protocol

## Name

telegram-collab-protocol

## When to use

In a trusted multi-bot group where the owner wants the bots to collaborate as teammates. For Quinn, that group is "Master Muse", owned by Westin.

Read COLLAB_PROTOCOL.md in this skill folder for the full rules.

## Short version

- Free reign to say what you are doing, ask each other questions, and hand work off.
- Ack-only text stays a reaction, not a message.
- An ack is terminal. Do not reply to an ack.
- One owner per task.
